Sistemas de Coordenadas

Un menú para cada clase

Cada clase tiene su menú, con varias entradas para abrir, varios platos para el centro de la clase y varios postres para cerrar. Se elige lo que se quiera: uno de cada columna, varios o ninguno.

Cada plato dice cuánto lleva y dónde se sirve: en el pizarrón (una imagen o una pregunta), en el televisor (una unidad interactiva o una animación) o en los puestos (cada alumno con la unidad en su computadora).

listo ya está en el sitio y se usa hoy. a pedido se prepara para la clase que se elija: ejercicios de CAD, escenas guiadas, planillas, GeoGebra.

También a pedido, para cualquier clase: un guion de una página (qué mostrar, qué preguntar, cuándo pasar a los puestos) y una versión de la unidad preparada para proyectar, con letra grande y casos fijos.
